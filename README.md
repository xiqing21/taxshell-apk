# taxshell — 个税模拟器（本地完整版）

基于 **Tauri 2（Rust + 系统 WebView）** 的个税模拟器。**v1.1.0 起核心功能全本地化：无登录、无卡密、无服务器验证、无付费。**

## ✨ 本地完整版功能（全部离线可用）

| 功能 | 说明 |
|---|---|
| 💰 收入纳税明细 | 选年度+所得类型 → 官方同款蓝顶汇总条 + 月度卡片列表 |
| 📄 明细详情 | 30+ 字段：本期收入/免税收入/减除费用/五险一金四项/专项扣除/税率/速算扣除数 |
| 🧾 纳税记录开具 | 起止年月 + 滑块验证 → 生成 16 位验证码（X 开头，同官方新规），跨年自动分段 |
| 🖼️ 预览导出 | Canvas 绘制官方《个人所得税纳税记录》版式：斜排水印 + 验证二维码 + 红色公章 → 保存 PNG 到相册 |
| ✏️ 数据管理 | 纳税人信息（姓名/证件）、五险一金比例、专项附加扣除、**一键生成年度数据**、单年重算/删除 |
| 📋 申报记录 | 按年度汇总申报期数/收入/税额 |
| 🗂️ 记录相册 | 已开具记录索引，可重新导出图片 |

### 计税引擎（tax-core.js）
- **累计预扣法**（工资薪金）：累计应纳税所得额 = 累计收入 − 5000×月数 − 累计五险一金 − 累计专项附加
- 7 级超额累进税率表（3%~45%），每月税额 = 累计应纳税额 − 已缴累计（自动处理税率跳档）
- 验证过的算例：月薪 15000 × 12 月 → 全年税 5430.00 元（与手工一致）

### 数据存储
全部存 localStorage（本机），**无任何网络请求**（可开飞行模式验证）。

## 🔄 与官方在线版的关系

启动页保留两个官方 H5 入口（getjob68.club / 175.24.180.44），需要看真实数据时可用。
本地版与官方数据互不相通——本地版就是让你**自定义**数据用的。

## 🔧 自定义/二次开发

- 改页面：`dist/app/*.html`（纯 HTML/JS，无构建步骤）
- 改计税/数据结构：`dist/app/tax-core.js`
- 改启动页入口：`dist/index.html`
- 重新构建：
  ```bash
  export ANDROID_HOME=$HOME/Library/Android/sdk
  export NDK_HOME=$ANDROID_HOME/ndk/27.0.12077973
  cargo tauri android build --apk --target aarch64
  ```
